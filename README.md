# SSB Signal Generation and Analysis (GNU Octave)

This project generates Upper Sideband (USB) and Lower Sideband (LSB) signals
from a given message signal using GNU Octave.

## Features
- Generates SSB signals
- Plots time-domain waveform
- Displays amplitude spectrum using FFT

## Tools
- GNU Octave

## Concepts Used
- Amplitude modulation
- Frequency spectrum analysis
- Signal processing
